# Optional menu card font

For sharp, readable text on generated restaurant menu images, upload **DejaVuSans.ttf** and **DejaVuSans-Bold.ttf** to this folder on your server.

Download (free license): https://dejavu-fonts.github.io/

Without these files, the server falls back to Windows Arial/Segoe or built-in GD bitmap fonts (small and hard to read on phones).
