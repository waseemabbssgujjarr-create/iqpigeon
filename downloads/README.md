# Upload your Android app here

Place your built APK at:

```
downloads/sales-app.apk
```

Full server path (cPanel File Manager):
```
public_html/downloads/sales-app.apk
```
(or wherever your site root is — same folder as `index.php`, then `downloads/sales-app.apk`)

The landing page will show **Get Android App** buttons automatically when this file exists.

After uploading a new APK, replace the file (same name). No code changes needed.
